# SOLACE photoreal support assets

- `misty_pines_4k.exr`: **Misty Pines**, Greg Zaal, Poly Haven. CC0.
- Asset page: https://polyhaven.com/a/misty_pines
- Download: https://dl.polyhaven.org/file/ph-assets/HDRIs/exr/4k/misty_pines_4k.exr
- API declared size: 27,877,625 bytes; MD5 a38520bb4bac8f1b6308d184b76995a5.
- Misty Pines was tested in rounds 2/3 and superseded, not used as final environment.
- Final environment: **Forest Slope**, Andreas Mischok, Poly Haven, CC0: https://polyhaven.com/a/forest_slope. Download https://dl.polyhaven.org/file/ph-assets/HDRIs/exr/4k/forest_slope_4k.exr. 30,882,783 bytes, MD5 0a9d1978e498c7420d5e1dabfb86d24c. Tilt/rotation/color temperature adjusted to canopy-and-sky composition. Distant environment is a photographic approximation, not a reconstruction of exact source trees.
- Fabric relief: **Rough Linen**, colormass (photography), Rico Cilliers (processing), CC0: https://polyhaven.com/a/rough_linen. Only the scanned roughness map is used for fine relief; the source blue diffuse color is not applied. Download https://dl.polyhaven.org/file/ph-assets/Textures/jpg/2k/rough_linen/rough_linen_rough_2k.jpg. 4,655,974 bytes, MD5 fb70674c782d6bead54c8baaae2b77db. Normal map downloaded for evaluation but not used.
- Near pine geometry: **Pine Sapling Small**, CC0, credited and documented in `pine_sapling_small/PROVENANCE.md`. Variant A instanced, original compact diffuse/normal/roughness and alpha textures used. Corrected multi-variant display offsets before final render.
- Used images are packed into the delivered blend; original downloaded source packages remain local. Provenance remains in Git without duplicate heavy image packages.
- Other new modeled assets are original procedural Blender geometry/materials reconstructed against owner-supplied SOLACE stills. No paid generation, no source-video projection onto the interior.
